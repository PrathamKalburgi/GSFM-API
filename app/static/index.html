Architecture
Design specifications & guarantees

Planar UTM Projection

Coordinates in degrees are never measured directly. The service derives the bounding extent, selects the central UTM zone, and projects all coordinates before computing planar area and length.

Isolated Layer Ingestion

KML folders and Shapefile layers are ingested independently. Layer boundaries are preserved to prevent cross-layer property pollution and handle disjoint attribute schemas.

Archive Security

Strict memory guards defend against zip traversal and zip bombs. Only necessary Shapefile members (.shp, .shx, .dbf, .prj) are extracted into isolated temp directories under generated names.

PostgreSQL 17 Storage

Persisted in Supabase PostgreSQL with native JSONB columns for geometry and attribute schemas. Database foreign keys enforce cascade deletion, and Row Level Security is enabled.

Geodesic Oracle Validation

The calculation pipeline is benchmarked against pyproj.Geod ellipsoidal geodesics within 0.1% accuracy tolerance across multiple continents and latitudes.

Containerized Deployment

Packaged with bundled geospatial wheels avoiding system GDAL installations. Runs under a non-root user with automated database migrations and health monitoring.
